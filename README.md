# RemoteDeck website

Static public information site for the RemoteDeck private preview. This repository contains no application source code, credentials or builds.

GitHub Pages: publish from `main` / `(root)`.

Production URL: https://remotedeck.djsonic-labs.com/

The local workspace explorer demonstrates SSH animation, a conceptual SFTP file browser and an RDP profile. It does not open real connections, access files, or collect telemetry. JavaScript is optional; the SSH transcript remains visible without it. Preserve CNAME, Google verification file, and the published privacy/terms URLs.
